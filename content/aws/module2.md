aws pricing model, 3 fundamental drivers of cost with aws

- compute
- storage
- data transfer

reserved instances(RIs) by aws

- AURI; all upfront
- PURI; partial upfront
- NURI; no upfront

services with no charges

- amazon vpc
- elastic beanstalk
- auto scaling
- aws cloudformation
- aws identity and access management(IAM)

total cost of ownership(TCO)
it is the financial estimate to help identify direct and indirect costs of system.
TCO considerations
server costs
storage costs
network costs
IT labor costs

aws organizations
its a free acc management service that enables u to consolidate multiple aws acc into an organization that u create and centrally manage.

- aws management console
- aws command line interface
- aws software development kits
- aws organizations https query api

aws budgets uses the cost visualization that is provided by cost explorer to show u the status of ur budgets and to provide forecasts of ur estimated costs.
budget alerts can be sent via email or via amazon simple notification service(amazon sns).
