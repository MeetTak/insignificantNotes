3 legs of spring triangle

1. dependency injection
2. portable service abstractions
3. aspect oriented programming

a proxy in spring is a dynamically generated subclass of an obj that can add additional behavior to the original object without modifying its source code. it uses runtime code generation to intercept method calls and add extra functionality like logging or transaction management.

the jdbc template and jdbc client provide a higher lvl abstraction for database operations, reducing boilerplate code and simplifying database interactions.

aspect oriented programming in spring is a technique for adding cross-cutting concerns like logging, timing, or transaction management to multiple obj without modifying their original source code.

monolithic single file structure refers to a software design methodology where an entire application-including user interface user interface, business logic, and data access layers-is developed, deployed, and managed as one unified executable unit or a single codebase.
